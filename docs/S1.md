# S1 — Système de compréhension de la question

Statut : ✅ VALIDÉ — 32 tests passent

## Entrée
- Question en français (str)
- client_config.yaml chargé via ClientContext

## Sortie
intent.json :
```json
{
  "intention": "conformite | comparaison_groupes | tendance | anomalie",
  "piece": "M2L1A1C",
  "operation": "FILAGE | EQUATOR",
  "variables": ["CR1", "CR2", "CR3"],
  "group_by": "PAS_E_Fournisseur",
  "filtres": {
    "Designation_Reference": "M2L1A1C",
    "Operation": "FILAGE",
    "Date_debut": "2026-03-22",
    "Date_fin": "2026-05-22"
  },
  "clarification_needed": false,
  "clarification_manque": [],
  "contexte_session": {}
}
```

## Champs intent.json

| Champ | Type | Obligatoire | Description |
|-------|------|-------------|-------------|
| intention | str | oui | Type d'analyse demandée |
| piece | str ou list | non | Modèle de pièce |
| operation | str | non | FILAGE ou EQUATOR |
| variables | list | oui | Tags à analyser |
| group_by | str ou list | non | Colonne(s) de regroupement |
| filtres | dict | oui | Filtres à appliquer sur les données |
| clarification_needed | bool | oui | true si intent incomplet |
| clarification_manque | list | oui | Ce qui manque |
| contexte_session | dict | oui | Mémoire conversationnelle |

## Pipeline — 5 agents

### Agent 1 — Préprocesseur (Python pur)
Normalise la question. Détecte les expressions
temporelles via dateparser (calendaires) ou jetons
logiques (événements industriels définis dans
le YAML section temps.evenements).
Injecte le contexte session si disponible.

### Agent 2 — Extracteur d'entités (Python pur)
Parcourt la question et cherche des correspondances
dans la section entites du YAML via :
1. Fuzzy matching (RapidFuzz token_sort_ratio)
2. Similarité vectorielle (all-MiniLM-L6-v2)
3. Fusion RRF
Produit une liste de candidats par concept
(pièce, opération, facteur, variable, intention)
avec scores consolidés.

### Agent 3 — Désambiguïseur (LLM 7b)
Intervient UNIQUEMENT si score entre 0.70 et 0.85.
Reçoit le terme ambigu + 3 meilleurs candidats.
Choisit parmi les candidats (classification).
Ne génère rien de nouveau.
Score >= 0.85 → bypassé (Python décide).
Score < 0.70 → bypassé (Agent 5 clarification).
Timeout 10s, 3 tentatives, fallback Python.

### Agent 4 — Constructeur d'intent (Python pur)
Assemble les entités résolues en intent.json.
Règles déterministes :
- Si facteur = matrice → opération = EQUATOR
- Si facteur = fournisseur → opération = FILAGE
- Si pièce absente → clarification_needed = true
- Si multi-facteurs → group_by = liste
- Variables = tous tags de pièce+opération si non spécifié
Valide que variables existent dans le YAML pour
la combinaison pièce+opération.

### Agent 5 — Clarificateur (LLM 7b)
Intervient UNIQUEMENT si Agent 4 produit
clarification_needed = true.
Python détermine CE QUI manque et LES OPTIONS
disponibles depuis le YAML.
Le LLM rédige uniquement la phrase de clarification
avec les options imposées par Python.
Timeout 10s, 3 tentatives, fallback template Python.

## Mémoire conversationnelle
Gérée par pipeline.py (Python pur).
Dict session avec dernier intent validé.
"Et pour M2L1B ?" → Python substitue la pièce.
Le LLM ne déduit JAMAIS la continuité.

## Lien S1 → S2
S2 consomme intent.json tel quel.
Champs que S2 utilise en priorité :
- filtres (pour construire la requête SQL)
- variables (pour le pivot Long → Large)
- group_by (pour structurer le df_propre)
Les jetons logiques temporels (EVENT_*)
sont résolus par S2 via requête SQL.

## Tests de validation — 5 questions LISI

1. "Les pièces M2L1A1C sont-elles conformes au filage ?"
   → intention=conformite, piece=M2L1A1C, operation=FILAGE

2. "La matrice a-t-elle un impact sur la forme intrados de M2L1B ?"
   → intention=comparaison_groupes, piece=M2L1B,
     operation=EQUATOR (inféré), group_by=Ref_Matrice

3. "Qui d'entre la matrice et le four impacte le plus M2L1B ?"
   → intention=comparaison_groupes, piece=M2L1B,
     operation=EQUATOR, group_by=[Ref_Matrice, Numero Machine]

4. "Est-ce que nos pastilles depuis 2 mois sont bonnes sur M2L1A1C ?"
   → intention=conformite, piece=M2L1A1C,
     operation=FILAGE (inféré), Date_debut=aujourd'hui-60j

5. "Est-ce que le fournisseur a un impact sur la qualité ?"
   → clarification_needed=true, propositions=10 modèles
