# S5 — Interprétation métier vérifiée

## Entrée
- intent.json (S1)
- sortie S3 : specialist_results, metrics_summary
- sortie S4 : descriptions_tabulaires, tables (jamais png_bytes)
- profile : operateur | technicien | ingenieur | directeur
- ClientContext (S0) — profils, tokens_max, forbidden_words

## Sortie
```json
{
  "interpretations": [
    {"specialist": "cp_cpk", "texte": "...", "statut": "Accept"}
  ],
  "synthese": "...",
  "fidelite_score": 0.92,
  "warnings": [],
  "error": null
}
```

## 7 passes
| Passe | Mode | Rôle |
|-------|------|------|
| R1 | LLM 14b | Interprétation par spécialiste (prompt pré-formaté) |
| R2 | Python | Vérification chiffres (Accept / Review / Reject) |
| R3 | LLM 14b | Interprétation graphiques (descriptions texte uniquement) |
| R4 | Python | Cohérence inter-spécialistes |
| R5 | LLM 14b | Correction sections Review / flags R4 |
| R6 | LLM 14b | Synthèse profil |
| R7 | Python | Contrôle forbidden_words + tokens_max |

## Règles absolues
- LLM = rédacteur uniquement
- Timeout 10s, 3 tentatives, fallback Python
- File FIFO : 1 appel LLM à la fois
- Fidélité : écart <1% Accept, 1-5% Review, >5% Reject
- Zéro accès CSV/Parquet
