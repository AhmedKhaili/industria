# S5 — Interprétation métier vérifiée

## Entrée
- intent.json (S1)
- sortie S3 : specialist_results, metrics_summary
- sortie S4 : descriptions_tabulaires, tables (jamais png_bytes)
- profile : operateur | technicien | ingenieur | directeur
- ClientContext (S0) — profils, tokens_max, forbidden_words

## Sortie
```json
{
  "interpretations": [
    {"specialist": "cp_cpk", "texte": "...", "statut": "Accept"}
  ],
  "synthese": "...",
  "fidelite_score": 0.92,
  "warnings": [],
  "error": null
}
```

## 7 passes
| Passe | Mode | Rôle |
|-------|------|------|
| R1 | LLM 14b | Interprétation par spécialiste (prompt pré-formaté) |
| R2 | Python | Vérification chiffres (Accept / Review / Reject) |
| R3 | LLM 14b | Interprétation graphiques (descriptions texte uniquement) |
| R4 | Python | Cohérence inter-spécialistes |
| R5 | LLM 14b | Correction sections Review / flags R4 |
| R6 | LLM 14b | Synthèse profil |
| R7 | Python | Contrôle forbidden_words + tokens_max |

## Interprétation Cpk métier (point E)

- Prompt R1 : consigne dispersion / centrage / conformité (pas lecture tabulaire).
- Fallback Python : phrases métier selon seuils Cpk (&lt; 1,0 critique, &lt; 1,33 limite).
- `dunn_posthoc` : fallback liste des paires significatives.

## Synthèse PDF (point D)

- Corpus R6 : libellés métier (`Capabilité processus`, etc.), pas `cp_cpk` / `analysis_context`.
- Termes interdits : `recommandations.synthese_interdits` dans le YAML client.
- R6 + R7 : `sanitize_synthesis_text()` retire les identifiants internes restants.

## P3 — Portrait (R2 étendu + agregee_python)

### R2 — champs de référence
- `descriptive` : moyenne, médiane, écart-type, variance, skewness, kurtosis, min/max, quartiles, pct hors tolérances, centrage
- `normality` : statistique, p-value
- `distribution_fit` : aic_min, bic_min
- Reject qualitatif si loi ou verdict_normalite contredits ; interdit « loi probable »

### Phrases certifiées (`systems/stats_format.py`)
- `certified_normalite_phrase` — jamais « loi probable »
- `certified_loi_candidate_phrase` — « meilleur ajustement selon AIC »

### Multi-variables (YAML `analyse_etendue.synthese_s5`)
- **R1** : LLM sur **chaque** spécialiste (qualité maximale), quel que soit le nombre de variables
- Si `variables > avertissement_si_variables_gt` (défaut 3) : **warning** S5 informatif (durée), pas de changement de mode
- **`zero_llm_synthese: true`** (opt-in explicite) : fallbacks R1 + `assemble_synthesis_python()` en R6 — jamais automatique

## Règles absolues
- LLM = rédacteur uniquement
- Timeout 10s, 3 tentatives, fallback Python
- File FIFO : 1 appel LLM à la fois
- Fidélité : écart <1% Accept, 1-5% Review, >5% Reject
- Zéro accès CSV/Parquet
