# S7 — Rapport PDF EN9100 (traçable, archivable)

## Objectif produit

Produire le document que tient un **auditeur** ou un **directeur qualité** : rapport structuré, lisible, **sans dict Python brut**, avec **empreinte SHA-256** et conformité au `contrat_rapport` du YAML client.

> Un technicien a posé une question ; S1–S6 ont produit métriques, graphiques, interprétations vérifiées et recommandations. **S7 assemble et signe** — il ne recalcule rien, n’invente rien.

**Ambition** : niveau **rapport scientifique + opérationnel** (LISI / EN9100) — pas une simple impression de logs.

---

## Cohérence PHILOSOPHY — points tranchés

| Règle | Spec Claude | Décision S7 v4 |
|-------|-------------|----------------|
| **§8 Agent 6c** | Zéro LLM mise en page ; option « titre LLM » | **Zéro LLM dans S7** — titres et libellés depuis YAML + `formatters` |
| **§21 SHA-256** | `question + intent + specialist_results + recommandations + timestamp` | **Payload canonique v4** (ci-dessous) — à valider comme mise à jour explicite de §21 pour le pipeline v4 |
| **§8 judge_warnings** | — | **Jamais** le texte des `warnings` S5/S6 dans le corps ; compteur en annexe traçabilité uniquement |
| **§9 styles** | Réutiliser `enterprise/report/` | Via **`report_port.py`** (import lazy) — pas d’import `enterprise` ailleurs dans `systems/s7/` |
| **§20 licences** | Même pattern que `rag_port` S6 | `systems/s7` = open core ; rendu PDF = port vers `enterprise/report` (BSL) |
| **§22 couleurs σ** | — | Graphiques déjà générés en S4 (Plotly) ; S7 **intègre les PNG** sans recoloriser |
| **contrat_rapport YAML** | must_have / must_not | **A4 Validateur** — loi métier ; warning si violation, pas blocage |

### Contradiction résolue — SHA-256

PHILOSOPHY §21 (v3) : `question + json_compact + rapport_oapc + timestamp`.

**S7 v4** — empreinte sur contenu **figé avant mise en page** :

```text
SHA256( UTF-8(
  question_originale
  + JSON(intent, sort_keys=True)
  + JSON(specialist_results, sort_keys=True)
  + JSON(recommandations S6, sort_keys=True)
  + synthese_S5
  + synthese_action_S6
  + fidelite_score
  + timestamp_ISO8601
) )
```

- **Exclu du hash** : `pdf_bytes`, interprétations graphiques S5, warnings, png.
- **Inclus** : ce qui prouve la décision métier (métriques + textes de synthèse + actions).
- **Affichage PDF** : hash **complet** en pied de page + fichier sidecar `.json` (même hash, métadonnées).

> Validation requise : amendement formel de PHILOSOPHY §21 pour le pipeline v4.

## Modèle intermédiaire — « mâcher le travail » (zéro LLM)

A1 produit un **`ReportDocument`** : liste de sections déjà **sanitisées** (`sanitize_for_pdf`, `format_value`, `format_number` + unités YAML).

Chaque bloc = type + données prêtes pour ReportLab :

| `block_type` | Source | Règle |
|--------------|--------|--------|
| `cover` | intent + ClientContext | Client, pièce, opération, date, profil, question |
| `verdict` | S6 `priorite_max` | GO / NO-GO / SURVEILLANCE — **première page** (contrat YAML) |
| `executive` | S5 `synthese` + S6 `synthese_action` | Paragraphes ; pas de bullets brutes |
| `recommendations` | S6 liste | Tableau : priorité, action, responsable, délai ; couleur P1–P4 via `styles.COLORS` |
| `charts` | S4 `graphs[]` | Image PNG + légende `description` ; unité axe depuis YAML tolérances |
| `metrics_table` | S3 + S4 `tables` | Lignes Cpk / ANOVA formatées ; **pas** de `repr(dict)` |
| `interpretations` | S5 | Par spécialiste ; badge `Accept` / `reject` / `fallback` |
| `traceability` | A3 | SHA-256 complet, timestamp, version, nb warnings |
| `annexe_warnings` | comptage | « N avertissements système » — **pas** le texte des warnings |

### Profil opérateur (contrat `ne_doit_jamais`)

- Masquer **p-value**, Cpk, ANOVA dans tableaux et interprétations (réécriture Python : « écart par rapport à la cible », « conformité »).
- Graphiques : légendes déjà sans jargon si descriptions S4/S5 filtrées en amont.

### Profil directeur

- Sections courtes : verdict + exécutif + recommandations agrégées (déjà filtré S6).
- Graphiques : max N (config YAML `rapport_pdf.max_graphiques_directeur` — à ajouter).

## Ordre des sections (EN9100 + démo client)

Ordre **retenu** (diffère de Claude — actions avant preuves détaillées) :

1. **Page de garde** — identité client, question, date, profil  
2. **Verdict GO / NO-GO** — dérivé de la priorité S6 max (P1 → NO-GO, P2 → intervention, P3/P4 → surveillance / GO sous réserve)  
3. **Résumé exécutif** — S5 + S6 (paragraphes)  
4. **Plan d’action** — recommandations S6 (tableau priorisé P1→P4)  
5. **Preuves visuelles** — graphiques S4 (PNG, LTI/LTS visibles sur histogrammes/boxplots)  
6. **Métriques détaillées** — tableaux S4 + lignes clés S3  
7. **Interprétations** — textes S5 vérifiés  
8. **Traçabilité** — SHA-256, fidélité, version IndustrIA  
9. **Annexe** (optionnelle) — compteur warnings, liste spécialistes exécutés  

> Justification : un auditeur lit d’abord **verdict + actions**, puis **preuves**.

## Architecture — 4 agents

| Agent | Mode | Rôle |
|-------|------|------|
| **A1** `assembler` | Python | `ReportDocument` + filtre profil + verdict + contrat métier |
| **A2** `renderer` | Python | `pdf_bytes` via `report_port` → ReportLab + styles/charts/formatters |
| **A3** `signer` | Python | SHA-256 + sidecar JSON |
| **A4** `validator` | Python | `contrat_rapport` YAML → warnings |

### A1 — Assembleur (Python pur)

- Lit **uniquement** les sorties S3–S6 + `intent` + `ClientContext`.
- Calcule `priorite_max` depuis S6 (`P1` > `P2` > …).
- Verdict :
  - `P1` → **NO-GO** (arrêt / action immédiate)
  - `P2` → **NO-GO opérationnel** ou « intervention urgente »
  - `P3` → **SURVEILLANCE**
  - `P4` seul → **GO**
- Interprétations en `reject` : afficher texte avec mention **« données certifiées (écart LLM corrigé) »**.
- **Ne pas** inclure `interpretations` dont le seul contenu est `Graphique : …` (doublon S4) — filtre `specialist == graphique`.

### A2 — Rendu PDF (`report_port.py` + `renderer_stub.py`)

- **`report_port.py`** : seul point d’import lazy `enterprise.report.*` (styles, formatters) via `importlib`.
- **`renderer_stub.py`** : moteur ReportLab autonome ; utilisé en CI et si `enterprise/` indisponible.
- En prod : `report_port` charge dynamiquement styles/formatters enterprise et les injecte dans `renderer_stub` — **aucun fichier créé dans `enterprise/`**.
- Tests : `report_renderer=renderer_stub.render_pdf` ou stub injecté dans `S7Pipeline`.

### A3 — Signer (Python pur)

1. Sérialiser payload canonique (UTF-8, JSON trié).
2. `hashlib.sha256`.
3. Injecter dans bloc `traceability` du PDF.
4. Écrire `reports/rapport_<piece>_<op>_<timestamp>.meta.json` (gitignored si besoin).

### A4 — Validateur (Python pur)

Charge `context.raw["contrat_rapport"]` :

| Règle YAML | Vérification A4 |
|------------|-----------------|
| Verdict première page | `verdict` dans sections[0..2] |
| Cpk + interprétation | au moins une ligne Cpk si `cp_cpk` dans S3 |
| Graphique + LTI/LTS | au moins 1 PNG S4 ; warning si `chart.error` |
| Recommandation + délai | `len(recommandations) >= 1` |
| Unité sur axes | description contient unité YAML ou warning |
| Pas p-value opérateur | scan texte si profil `operateur` |
| Pas conclusion sans action si Cpk < 1.33 | si min(Cpk) < 1.33 → au moins une reco P1/P2 |

Violations → `warnings[]`, **PDF généré quand même** (traçabilité des écarts).

## `report_port.py` — wrapper lazy

## 5 tests de validation (`test_s7_lisi.py`)

| # | Test | Vérifie |
|---|------|---------|
| 1 | **PDF non vide** | `len(pdf_bytes) > 5000`, header `%PDF` |
| 2 | **SHA-256 stable** | deux appels même entrée → même hash |
| 3 | **Verdict NO-GO** | S6 avec P1 → texte verdict NO-GO page 1 (extract texte ou marker) |
| 4 | **Contrat opérateur** | profil `operateur` → pas de « p-value » / « Cpk » dans texte extrait |
| 5 | **Chaînage S1→S7** | question LISI réelle → PDF + sidecar + `error is None` |

Tests **sans Ollama** (S7 = Python pur). Chaînage 5 : réutilise cache Parquet ; timeout généreux.

### Tests critiques (phase 2 — `test_s7_critical.py`)

- S3 vide → PDF avec placeholders, pas de crash  
- `reject` S5 visible comme donnée certifiée  
- `report_port` stub → PDF minimal  
- SHA exclut bien les `png_bytes`
