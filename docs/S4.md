## Dispatcher — intention → graphiques

| Intention | Graphiques |
|-----------|------------|
| conformite | histogram |
| comparaison_groupes | boxplot |

| anomalie | timeseries |

## Règles absolues
- Zéro LLM
- Zéro accès CSV/Parquet
- Variables depuis `intent.variables`
- Limites LTI/LTS via `ClientContext.get_tolerance()`
- Graphiques : Plotly dans `chart_builder.py` pour **boxplot** et **histogramme** (LTI/LTS/Nominal tracés sur le graphique)
- `enterprise/report/charts.py` : timeseries et fallback uniquement — **non modifié** (BSL)
- S5 ne reçoit que `descriptions_tabulaires` et `tables`, jamais les PNG

## Lien S3 → S4 → S5
S4 consomme les métriques S3 pour enrichir les tableaux.
S5 interprète les descriptions tabulaires uniquement.

## Tolérances sur les graphiques (point C — démo LISI)

| Type | Axe des valeurs | Lignes |
|------|-----------------|--------|
| histogram | x (mesure) | LTI, LTS, Nominal (`add_vline`) |
| boxplot | y (mesure) | LTI, LTS, Nominal (`add_hline`) |

Les limites viennent de `ClientContext.get_tolerance(piece, operation, variable)`.
