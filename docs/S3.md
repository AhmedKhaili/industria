## Dispatcher — intention → spécialistes

| Intention | Spécialistes |
|-----------|-------------|
| conformite | cp_cpk, zscore, spc |
| comparaison_groupes | anova_kruskal, cp_cpk (+ dunn_posthoc si ANOVA/Kruskal significatif) |
| tendance | mann_kendall, ewma_cusum, regression |
| anomalie | zscore, spc, ewma_cusum |

## Pre-gates Python pur
- n < 10 → pas de Cp/Cpk ni ANOVA
- 1 seul groupe unique → pas d'ANOVA
- Pas de LTI/LTS dans YAML → pas de Cp/Cpk
- Colonne group_by absente → pas d'ANOVA

## Règles absolues
- Zéro LLM
- Zéro accès CSV/Parquet
- Tolérances lues via ClientContext uniquement
- Spécialistes réutilisés depuis specialists/
- Résultats toujours structurés même si erreur

## Dunn post-hoc (point A)

Si `anova_kruskal` est **significatif**, S3 exécute automatiquement `dunn_posthoc` (`scikit-posthocs`, correction Bonferroni).

Sortie : `paires_significatives[]` avec `groupe_a`, `groupe_b`, `p_value`, `libelle`.

## Pire matrice / pire groupe (point B)

Après exécution des spécialistes, `group_ranking.compute_worst_group()` :

1. **Variable pivot** : Cpk minimum parmi les résultats `cp_cpk` (règle YAML `recommandations.pire_matrice.variable_pivot`).
2. **Ex-aequo variables** : plus fort `%` hors LTI/LTS sur la série globale (`ex_aequo: pct_hors_tolerance`).
3. **Pire groupe** (`group_by`, ex. `Ref_Matrice`) : max `%` hors tolérance sur la variable pivot.

Sortie : `s3_output["group_ranking"]` + copie dans `metrics_summary["group_ranking"]`.

## Lien S2 → S3 → S4
S3 consomme df_propre uniquement.
S4 consomme specialist_results pour les graphiques.

## Extension analytique (S3-extended v1.1)

Spec validée : **`docs/S3-extended.md`**.

### P0 — corrélation (`analyse_complete`)

- Intention S3 : **`analyse_complete`** uniquement (pas d'intention `correlation` dédiée).
- Dispatcher : `analyse_complete` → `["correlation"]` (P1 étendra la liste).
- Executor : `correlation` en famille **`multi_target`** (1 exécution par variable de l'intent).
- Module : `specialists/correlation.py` (Pearson / Spearman / Kendall).
- Test : `systems/s3/tests/test_s3_correlation_lisi.py`.

Intent minimal (S1 `analyse_complete` = P2 ; en attendant intent manuel ou partiel) :

```python
{
  "intention": "analyse_complete",
  "piece": "M2L1A1C",
  "operation": "EQUATOR",
  "variables": ["CR90_INTRADOS_FORME", "CR70_INTRADOS_FORME", "CR90_INTRADOS_VRILLAGE"],
}
```

### P1 — portrait statistique

- Intentions S3 : **`portrait_statistique`** → `descriptive`, `normality`, `distribution_fit`.
- **`analyse_complete`** → portrait **puis** `correlation` (P0).
- Modules : `specialists/descriptive.py`, `normality.py`, `distribution_fit.py`.
- Fallbacks S5 : `enriched_descriptive_interpretation`, `enriched_normality_interpretation`, `enriched_distribution_fit_interpretation`.
- Tests : `systems/s3/tests/test_s3_portrait_p1.py`.

### P2+ (non démarré)

S1 intentions YAML, `diagnostic_causal`, extension `analyse_complete` (cp_cpk, ANOVA) — voir S3-extended §9.
