## Dispatcher — intention → spécialistes

| Intention | Spécialistes |
|-----------|-------------|
| conformite | cp_cpk, zscore, spc |
| comparaison_groupes | anova_kruskal, cp_cpk |
| tendance | mann_kendall, ewma_cusum, regression |
| anomalie | zscore, spc, ewma_cusum |

## Pre-gates Python pur
- n < 10 → pas de Cp/Cpk ni ANOVA
- 1 seul groupe unique → pas d'ANOVA
- Pas de LTI/LTS dans YAML → pas de Cp/Cpk
- Colonne group_by absente → pas d'ANOVA

## Règles absolues
- Zéro LLM
- Zéro accès CSV/Parquet
- Tolérances lues via ClientContext uniquement
- Spécialistes réutilisés depuis specialists/
- Résultats toujours structurés même si erreur

## Lien S2 → S3 → S4
S3 consomme df_propre uniquement.
S4 consomme specialist_results pour les graphiques.
